# [권나현] 개인 개발 보고서

**프로젝트명:** CODI-IT – 패션 이커머스 플랫폼  
**팀명:** 2팀  
**작성자:** 권나현  
**작성일:** 2025.10.26  
 
## 1. 프로젝트 개요

### 1-1. 프로젝트기간 : 09월 15일 ~ 11월 03일

### 1-2. 목적:
- 패션 이커머스 환경에서 판매자와 구매자가 효율적으로 소통하고 거래할 수 있는 통합 플랫폼 입니다. 
- 상품 관리부터 주문·결제·리뷰까지의 전 과정을 자동화하여 편리하고 안정적인 쇼핑 경험을 제공하는 서비스입니다.

### 1-3. 주요 기능:
| 모듈 | 주요 기능 |
|:------|:-----------|
| **S3 (이미지 업로드)** | 상품·스토어 이미지 업로드 지원 |
| **Auth (인증/인가)** | JWT 인증 + Refresh 토큰 쿠키 회전 |
| **User (회원)** | 회원가입/내 정보 조회·수정·탈퇴, 관심 스토어 조회 |
| **Store (스토어)** | 스토어 등록/수정/조회, 내 스토어 상세 조회, 등록 상품 조회, 관심 스토어 등록/해제 |
| **Product (상품)** | 상품 등록/목록/상세/수정/삭제, 상품 문의 등록/조회 |
| **Cart (장바구니)** | 생성/조회/수정(추가·수량)/아이템 상세·삭제 |
| **Orders (주문)** | 주문 생성/목록(페이지네이션)/상세/취소/정보 수정 |
| **Review (리뷰)** | 상품 리뷰 작성/목록/상세/수정/삭제 |
| **Inquiry (문의/답변)** | 내 문의 조회/상세/수정/삭제, 답변 상세 조회/수정/등록 |
| **Dashboard / Alarm / Metadata** | 판매·주문 지표, 알림, 메타데이터 관리 |

## 2. 주요 개발 내역

### 백엔드 (Express + Prisma)
- Prisma ORM을 활용한 DB 모델(Auth, User, Point) 설계 및 마이그레이션
- 구현 기능
   - Auth 모듈: 로그인, 리프레시 토큰 재발급, 로그아웃
   - User 모듈: 회원가입, 내 정보 조회 및 수정, 관심 스토어 조회, 회원 탈퇴
   - Point 모듈: 내 포인트 조회
   - Grade 모듈: 내 등급 조회
   - 전역 로깅 미들웨어: 요청(Request)과 응답(Response) 정보를 콘솔에 출력하도록 구현
- 테스트 및 검증
   - Auth, User, Point, Grade 모듈의 유닛 테스트 코드 작성
   - 주요 기능 동작 및 예외 처리 검증을 통해 안정성 확보
- 협업 및 관리
   - 이슈 템플릿, PR 템플릿 제작으로 협업 효율화
   - Wiki 문서 작성을 통한 프로젝트 구조 및 기능 명세 정리
- 기타 작업
   - User 프로필 사진 생성 기능 구현
   - 중간·최종 발표용 PPT 제작 및 구성 참여

### 프론트엔드/테스트
- Postman을 이용한 백엔드 API 단위 테스트 및 통합 테스트
- 프론트 연동 후 수정

## 4. 성과 및 배운 점
이번 고급 프로젝트에서는 기존에 익숙했던 Express 대신 Nest.js를 처음으로 적용하며 새로운 프레임워크의 구조와 철학을 직접 경험할 수 있었습니다.
Nest의 모듈화, 의존성 주입(DI), 데코레이터 기반 설계를 익히며 대규모 애플리케이션에서의 구조적 개발 방식을 이해하게 되었습니다.

또한 **인증/인가 로직(JWT 기반 로그인, 토큰 재발급, 로그아웃 등)**을 처음으로 직접 구현하면서 보안 처리와 세션 관리의 중요성을 배웠습니다.
이전 프로젝트에서는 Postman을 통해 단순 요청 검증만 했지만, 이번에는 **단위 테스트(Unit Test)**를 적용하여 기능 단위로 안정성을 검증하는 과정을 경험했습니다.

초급·중급 프로젝트를 거치며 다양한 문제를 해결했던 경험이 이번 프로젝트에서 큰 도움이 되었고,
이제는 전체적인 흐름을 파악하며 불필요한 코드 수정 없이 효율적으로 문제를 해결할 수 있게 되었다는 점에서 스스로의 성장을 느꼈습니다.

마지막으로, 팀원들과의 꾸준한 협업과 소통을 통해 기간 내에 프로젝트를 완성할 수 있었고,
결과물 또한 높은 완성도를 보여 만족스러웠습니다.

특히 실무에서도 널리 사용되는 Nest.js를 기반으로 프로젝트를 완성했다는 점이 큰 의미 있는 성과라고 생각합니다.

## 5. 향후 과제 및 개선 방향
이번 프로젝트를 통해 Nest.js의 구조와 백엔드 전반의 흐름을 이해했지만, 아직 아키텍처 설계와 테스트 코드의 깊이 있는 활용에는 보완이 필요하다고 느꼈습니다.
앞으로는 테스트 커버리지 확장과 예외 상황 처리 강화를 통해 안정적인 서버 운영이 가능하도록 개선할 계획입니다.

또한 현재는 단일 서버 구조로 되어 있지만, 향후에는 모듈 간 의존성 최소화 및 마이크로서비스 구조(MSA) 설계에 도전해보고 싶습니다.
이를 통해 유지보수성과 확장성을 높이고, 실제 서비스 환경과 유사한 시스템을 구축하는 것이 목표입니다.

프론트엔드와의 통신 과정에서도 더 나은 사용자 경험을 제공하기 위해 API 응답 구조 표준화와 성능 최적화를 진행할 예정입니다.
마지막으로, 협업 과정에서 배운 점을 바탕으로 문서화와 코드 리뷰 문화를 꾸준히 강화하여, 팀 전체의 개발 효율성과 코드 품질을 높이는 방향으로 나아가고자 합니다.
